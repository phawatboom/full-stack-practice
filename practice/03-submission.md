
## Decision explanation practice

Use this sequence when defending work: “The requirement was __. The constraints were __. I chose __ over __ because __. I verified it by __. The main limitation is __. I would reconsider when __.” Use your actual evidence rather than memorizing a speech.

## Weekly retrospective

- What can I now implement without generated code that I could not implement last week?
- Which bug did I investigate systematically? What evidence changed my mind?
- Which decision can I explain with an alternative and a trade-off?
- What did I estimate incorrectly, and how will I adjust the next estimate?
- What evidence is still missing? What single exercise should address it next week?
